Publications
RxnOptBench: Benchmarking LLMs for Reaction-Condition Optimization in Organic Methodology
Lingli Ge, Yubin Wang, Junyuan Gao, Jiahe Song, Jiaxing Sun, Boyu Zhu, Haote Yang, Jingchao Wang, Lixin Ma, Jiang Wu, Yuqiang Li, Conghui He
The 40th Annual Conference on Neural Information Processing Systems, Evaluations and Datasets Track, NeurIPS 2026 (CCF-A)
[PDF]
RxnOptBench evaluates how well large language models optimize chemical reaction conditions using real experimental data from organic methodology papers. It includes reaction screening options and literature precedents, with scores reflecting yield and stereoselectivity. Evaluations across frontier and chemistry-focused language models show substantial room for improvement in selecting the best conditions.
DianShi-RxnDB: A Large-Scale, Fine-Grained Organic Reaction Data Platform Built via a Fully Automated Pipeline for Researchers and AI Agents
Yubin Wang*, Xingjian Wei*, Jiang Wu*, Yinfan Wang, Boyu Zhu, et al.
Technical Report, 2026
[PDF] [Database]
DianShi-RxnDB is a large-scale organic reaction data platform built through an automated pipeline that extracts and normalizes information from patent text, images, and reaction schemes. It covers patents from the USPTO and EPO published between 1976 and 2025, with approximately 24 million reaction instances. The platform provides a web workbench for researchers and structured retrieval tools for AI agents.
NMRTrans: Structure Elucidation from Experimental NMR Spectra via Set Transformers
Liujia Yang*, Zhuo Yang*, Jiaqing Xie*, Yubin Wang*, Ben Gao, Tianfan Fu, Xingjian Wei, Jiaxing Sun, Jiang Wu, Conghui He, Yuqiang Li, Qinying Gu
The 32nd ACM SIGKDD Conference on Knowledge Discovery and Data Mining, AI4Science Track, KDD 2026 (CCF-A)
[PDF]
NMRTrans uses Set Transformers to elucidate molecular structures from experimental nuclear magnetic resonance spectra. The work introduces NMRSpec, a large corpus of experimental proton and carbon-13 spectra, and represents each spectrum as an unordered set of peaks. On experimental benchmarks, it improves Top-10 accuracy over the strongest baseline from 43.33% to 61.15%.
ActPrompt: In-Domain Feature Adaptation via Action Cues for Video Temporal Grounding
Yubin Wang, Xinyang Jiang, De Cheng, Dongsheng Li, Cairong Zhao
IEEE Transactions on Image Processing, TIP (CCF-A, SCI)
[PDF]
ActPrompt improves video temporal grounding by adapting pre-trained vision-language features to video domains and injecting action cues into the image encoder. It combines efficient in-domain feature adaptation with temporal prompting to distinguish actions from static visual content. Experiments show that the framework improves multiple existing grounding methods.
Exploring Interpretability for Visual Prompt Tuning with Cross-layer Concepts
Yubin Wang, Xinyang Jiang, De Cheng, Xiangqian Zhao, Zilong Wang, Dongsheng Li, Cairong Zhao
The 14th International Conference on Learning Representations, ICLR 2026 (CCF-A)
[PDF]
Interpretable Visual Prompt Tuning (IVPT) links visual prompts to human-understandable concept prototypes derived from image regions. It aggregates these regional features across model layers to explain prompts at different depths and semantic levels. Experiments on fine-grained classification benchmarks show strong performance and improved interpretability.
Uni2Det: Unified and Universal Framework for Prompt-Guided Multi-dataset 3D Detection
Yubin Wang*, Zhikang Zou*, Xiaoqing Ye, Xiao Tan, Errui Ding, Cairong Zhao
The 13th International Conference on Learning Representations, ICLR 2025 (CCF-A)
[PDF]
Uni²Det unifies multi-dataset 3D object detection with prompt modules that account for differences in data distributions and object taxonomies. Its multi-stage prompts integrate with existing detectors and support training across KITTI, Waymo, and nuScenes. Experiments show improved multi-dataset detection and generalization to unseen datasets.
Learning Domain Invariant Prompt for Vision-Language Models
Cairong Zhao*, Yubin Wang*, Xinyang Jiang, Yifei Shen, Kaitao Song, Dongsheng Li, Duoqian Miao
IEEE Transactions on Image Processing, TIP (CCF-A, SCI)
[PDF] [Code]
MetaPrompt learns domain-invariant prompts for vision-language models in few-shot settings. It combines visual and textual prompt tuning with asymmetric contrastive learning and domain-split updates to improve cross-class and cross-domain transfer. Results across base-to-new and domain-generalization benchmarks show stronger generalization than previous prompt-learning methods.
Learning Hierarchical Prompt with Structured Linguistic Knowledge for Vision-Language Models
Yubin Wang, Xinyang Jiang, De Cheng, Dongsheng Li, Cairong Zhao
The 38th Annual AAAI Conference on Artificial Intelligence, AAAI 2024 (CCF-A)
[PDF] [Code]
Hierarchical Prompt Tuning (HPT) uses language-model-generated graphs of category descriptions to bring structured knowledge into vision-language prompt learning. Relationship-guided attention captures links between entities and attributes, while hierarchical prompts combine local and global semantics. Experiments show improved effectiveness and generalization over previous approaches.
Hierarchical Identity Learning for Unsupervised Visible-Infrared Person Re-Identification
Haonan Shi, Yubin Wang, De Cheng, Lingfeng He, Nannan Wang, Xinbo Gao
IEEE Transactions on Image Processing, TIP (CCF-A, SCI)
[PDF]
Hierarchical Identity Learning (HIL) addresses unsupervised visible-infrared person re-identification by representing each identity cluster with multiple fine-grained centers. Multi-center contrastive learning improves representations within and across modalities, while bidirectional selection builds reliable cross-modal matches. Experiments on SYSU-MM01 and RegDB show improved retrieval performance.
Part-Based Multi-Scale Attention Network for Text-Based Person Search
Yubin Wang, Ding Qi, Cairong Zhao
Chinese Conference on Pattern Recognition and Computer Vision, PRCV 2022 (CCF-C, Oral)
[PDF]
Part-Based Multi-Scale Attention Network (PMAN) retrieves people from text by combining visual features at multiple scales with textual features. It uses a Bottleneck Transformer for representation learning and a cross-modal matching strategy to align descriptions with image regions. Experiments on CUHK-PEDES show improved person-search performance.
An Opinion Summarization-Evaluation System Based on Pre-trained Models
Han Jiang*, Yubin Wang*, Songhao Lv, Zhihua Wei
Rough Sets: International Joint Conference, IJCRS 2021
[PDF]
This system summarizes opinions in social media discussions using BERT-based subjectivity analysis and data-mining methods. It includes an evaluation module with hierarchical metrics to assess the resulting summaries. Experiments and ablation studies show that the pipeline produces concise summaries of the main opinions.

HPT++: Hierarchically Prompting Vision-Language Models with Multi-Granularity Knowledge Generation and Improved Structure Modeling
Yubin Wang, Xinyang Jiang, De Cheng, Wenli Sun, Dongsheng Li, Cairong Zhao
Artificial Intelligence, AI (CCF-A, SCI)
[PDF]
HPT++ extends hierarchical prompt tuning for vision-language models with multi-granularity knowledge generation and improved graph-based structure modeling. It strengthens relationship-aware attention and adds consistency constraints to the hierarchical text encoder.
